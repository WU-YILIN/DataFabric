## 模块业务流程 Mermaid 汇总

### 模块 1：Overview 总览

```mermaid
flowchart LR
  A["用户登录\n并选择租户 / 项目"] --> B["进入 Overview 总览页"]

  B --> C["读取项目关键指标\n（事件数 / 治理次数 / 通过率 / Pipelines 数）"]
  B --> D["读取最近治理活动\n（谁在什么时候审批了哪条事件）"]
  B --> E["读取风险与待办事项\n（高风险事件 / 未处理告警）"]

  C --> F["事件创建 / 修改\n（来自 Event Catalog）"]
  C --> G["治理检查请求\n（来自 Governance）"]
  C --> H["Pipeline 创建 / 状态变更\n（来自 Pipelines）"]
  C --> I["数据质量规则执行\n（来自 Data Quality）"]

  D --> J["写入治理审计日志\n（Audit Logs）"]
  E --> K["生成待办项\n指向具体事件 / 规则 / Pipeline"]

  F --> C
  G --> C
  H --> C
  I --> C
```

### 模块 2：Event Catalog（事件目录）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Event Catalog\n事件目录页"]

  B --> C["加载事件列表\n按租户 + 项目过滤"]
  C --> D["搜索 / 筛选事件\n（名称 / 域 / Owner / 状态 / 治理结果）"]

  D --> E["选择某个事件\n查看详情抽屉"]
  E --> F["查看事件基本信息\n（描述 / Owner / 标签）"]
  E --> G["查看 Schema\n（字段 / 类型 / 必填 / 描述）"]
  E --> H["查看治理记录\n（结论 / 风险 / 建议）"]
  E --> I["查看关联 Pipelines\n和数据质量规则"]

  B --> J["点击「新建事件」"]
  J --> K["填写事件基本信息\n（名称 / 描述 / 域 / Owner）"]
  K --> L["配置字段 Schema"]
  L --> M["保存为草稿\n写入事件目录 + 审计日志"]

  E --> N["编辑已有事件\n修改信息或 Schema"]
  N --> O["提交变更"]
  O --> P["记录版本与变更 diff\n写入审计日志"]
  O --> Q["可选择发起治理检查\n跳转 Governance Workbench"]
```

### 模块 3：Governance（治理工作台）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Governance\n治理工作台"]

  B --> C["从 Event Catalog\n选择待治理的事件\n或新建事件后跳转"]
  C --> D["加载当前事件定义\n（基本信息 + Schema）"]

  D --> E["事件 Owner 编辑事件定义\n补充/修改字段 & 元数据"]
  E --> F["点击「提交治理检查」"]

  F --> G["系统构造治理请求\n（事件定义 + 上下文 + 历史事件）"]
  G --> H["调用 LLM + 搜索引擎\n检索同租户内相似事件\n和治理规则"]

  H --> I{"生成治理结论"}
  I --> J["结论：通过\n返回通过状态 + 置信度\n可直接标记事件为「已通过治理」"]
  I --> K["结论：需修改\n返回风险列表 + 修改建议"]
  I --> L["结论：拒绝\n返回拒绝原因 + 高风险项"]

  K --> M["在右侧结果面板\n逐条查看风险与建议"]
  M --> N["一键应用部分建议\n自动更新事件描述/字段命名"]
  N --> O["再次提交治理检查\n进入下一轮评审"]

  J --> P["写入治理记录\n（结论 / 置信度 / 模型版本）"]
  K --> P
  L --> P

  P --> Q["写入审计日志\n（操作人 / 事件 / 结论 / 变更）"]
  P --> R["更新 Event Catalog 中\n该事件的治理状态标记"]
```

### 模块 4：Pipelines（数据通路）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Pipelines\n数据通路页"]

  B --> C["加载当前项目下\n所有 Pipelines 列表"]
  C --> D["按事件 / 状态\n搜索与筛选 Pipelines"]

  C --> E["选择某个 Pipeline\n查看详情（拓扑 + 状态）"]
  E --> F["查看拓扑视图\nEvent → Kafka Topic → Flink Job"]
  E --> G["查看状态时间线\n（Provision / Running / Failed / Rolled back）"]

  B --> H["点击「新建 Pipeline」"]
  H --> I["选择事件\n（已通过治理的事件）"]
  I --> J["配置通路参数\n（Topic 名称 / Job 模板 / 资源等级 等）"]
  J --> K["确认并提交创建请求"]

  K --> L["后端调用基础设施\n创建 Kafka Topic + 部署 Flink Job"]
  L --> M{"创建结果"}
  M --> N["成功\n记录 Pipeline 为 Running\n写入状态历史"]
  M --> O["失败\n记录 Pipeline 为 Failed\n写入失败原因"]

  E --> P["对现有 Pipeline 执行操作\n（暂停 / 恢复 / 回滚 / 手动同步）"]
  P --> Q["后端与实际集群交互\n更新 Job / Topic 状态"]
  Q --> R["定期或实时同步状态\n刷新前端列表与详情视图"]

  N --> S["写入审计日志\n（创建 / 启动 / 状态变更）"]
  O --> S
  P --> S
```

### 模块 5：Data Catalog（数据资产目录）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Data Catalog\n数据资产目录页"]

  B --> C["加载当前项目下\n所有数据资产列表\n（表 / Topic / View / 指标）"]
  C --> D["搜索 / 筛选资产\n（名称 / 类型 / 域 / 系统 / Owner / 状态）"]

  D --> E["选择某个资产\n打开详情抽屉 / 详情页"]
  E --> F["查看基础信息\n（名称 / 类型 / 所属系统 / 域 / Owner / 标签）"]
  E --> G["查看 Schema\n（字段 / 类型 / 分区 / 描述）"]
  E --> H["查看血缘（Lineage）\n上游 / 下游资产拓扑"]
  E --> I["查看质量与告警\n挂接的 DQ 规则与最近结果"]
  E --> J["查看关联事件与 Pipelines\n哪些事件 / 通路依赖此资产"]

  B --> K["点击「注册新资产」\n（或同步外部元数据）"]
  K --> L["填写资产元数据\n（来源系统 / 库 / 表名 / 类型 / 域 / Owner）"]
  L --> M["可选：导入或手动编辑 Schema"]
  M --> N["保存资产\n写入数据目录 + 审计日志"]

  E --> O["编辑已有资产元数据\n（Owner / 标签 / 域 / 描述 等）"]
  O --> P["提交变更\n记录版本与变更 diff"]
  P --> Q["写入审计日志\n并更新 Catalog 展示"]

  H --> R["血缘视图中\n点击上游/下游节点\n跳转到对应资产详情"]
```

### 模块 6：Data Quality（数据质量）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Data Quality\n数据质量模块"]

  B --> C["加载质量规则列表\n（按租户 + 项目过滤）"]
  C --> D["搜索 / 筛选规则\n（对象 / 类型 / 严重程度 / 状态）"]

  C --> E["选择某条规则\n查看规则详情"]
  E --> F["查看规则配置\n（目标资产 / 字段 / 条件 / 阈值 /严重程度）"]
  E --> G["查看最近执行结果\n通过率 / 失败次数 / 趋势图"]
  E --> H["查看告警记录\n（时间 / 对象分区 / 状态 / 处理人）"]

  B --> I["点击「新建规则」"]
  I --> J["选择目标资产\n（表 / Topic）和字段范围"]
  J --> K["选择规则类型\n（空值率 / 唯一性 / 范围 / 正则 等）"]
  K --> L["配置阈值与告警策略\n（阈值 / 严重程度 / 通知渠道）"]
  L --> M["保存并启用规则\n写入规则库 + 审计日志"]

  E --> N["编辑现有规则\n调整条件或阈值"]
  N --> O["保存变更\n生成新版本并记录 diff"]
  O --> P["写入审计日志\n并刷新规则列表展示"]

  Q["定时 / 调度系统\n执行质量检查任务"] --> R["对目标资产运行规则"]
  R --> S{"检查结果"}
  S --> T["通过\n记录执行日志\n更新最近结果"]
  S --> U["失败 / 告警\n生成质量告警\n推送通知 & 待办项"]

  T --> V["在规则详情页\n展示历史执行曲线"]
  U --> W["在 Overview / 待办中\n展示质量相关风险"]
```

### 模块 7：Scheduler（任务编排）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Scheduler\n任务编排模块"]

  B --> C["加载任务 DAG 列表\n（按租户 / 项目过滤）"]
  C --> D["选择某个任务 DAG\n查看拓扑与状态"]

  D --> E["查看 DAG 拓扑\n（上游任务 → 当前任务 → 下游任务）"]
  D --> F["查看调度配置\n（触发时间 / 依赖规则 / 重试策略）"]
  D --> G["查看最近实例列表\n（运行时间 / 状态 / 耗时）"]

  B --> H["点击「新建任务」或「新建 DAG」"]
  H --> I["选择任务类型\n（批处理 / 校验 / 下游同步 等）"]
  I --> J["配置任务节点\n（输入资产 / 输出资产 / 逻辑说明）"]
  J --> K["配置调度规则\n（Cron / 依赖触发 / 手动触发）"]
  K --> L["保存 DAG 定义\n写入调度配置 + 审计日志"]

  G --> M["选择某次运行实例\n查看详情"]
  M --> N["查看运行日志摘要\n（关键日志 / 出错节点）"]
  M --> O["查看上下游依赖状态\n定位是自身失败还是上游异常"]

  G --> P["对失败实例执行操作\n（重跑 / 跳过 / 标记成功）"]
  P --> Q["提交调度指令\n由调度引擎执行对应动作"]
  Q --> R["更新实例状态\n刷新实例列表与 DAG 视图着色"]

  S["自动调度引擎\n按配置触发任务"] --> T["生成运行实例\n写入运行记录"]
  T --> G
```

### 模块 8：Explore（查询工作台）

```mermaid
flowchart LR
  A["用户登录\n选择租户 / 项目"] --> B["进入 Explore\n查询工作台"]

  B --> C["选择数据源\n（仓库 / 数据库 / Catalog）"]
  C --> D["浏览库 / 表树\n（库 → 表 → 字段）"]

  D --> E["选择某个表\n查看字段与示例信息"]
  E --> F["将表名插入到 SQL 编辑器\n（FROM / JOIN 占位）"]

  B --> G["在 SQL 编辑器中编写 / 编辑查询语句"]
  G --> H["点击「执行查询」按钮"]

  H --> I["发送只读查询请求\n到对应数据源\n（带租户 / 项目上下文）"]
  I --> J{"执行结果"}

  J --> K["查询成功\n返回结果集"]
  K --> L["在下方结果区域展示\n表格形式 + 分页"]
  L --> M["支持导出结果\n（CSV / JSON 等）"]

  J --> N["查询失败\n语法错误 / 权限不足 / 资源限制"]
  N --> O["在结果区域展示错误信息\n+ 引导调整 SQL 或权限"]

  E --> P["基于字段信息\n补充查询条件 / 聚合逻辑"]
  P --> G

  Q["其他模块\n（如 Data Catalog / Event / DQ）"] --> R["一键跳转到 Explore\n预填相关表或示例 SQL"]
  R --> G
```
